# Security Policy

## Supported versions

Only the latest release of Java Structure Bar receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/ricky79/java-structure-bar/security/advisories/new).

Include a description of the problem, the steps to reproduce it and the plugin and IDE versions you used. You should get a first reply within a week.
